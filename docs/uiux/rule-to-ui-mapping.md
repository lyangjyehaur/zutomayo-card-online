# 官方規則 → UI 狀態映射表（Rule-to-UI Mapping）

> 規則來源：`docs/rules/official-start-guide-ui-analysis.md`
> 元件來源：`src/ui/game/`；互動細節：`docs/uiux/interaction-flow.md`

| 官方規則 / 概念                             | UI 呈現                                                                                    | 互動方式                                   | 狀態提示                                                                                             | 響應式處理                                        |
| ------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Deck 20 cards                               | `DeckZone`（牌背堆疊＋剩餘數）                                                             | 不可檢視（資訊隱藏）                       | 張數常駐；低張數即敗北風險由玩家讀數判斷                                                             | 全斷點顯示；橫屏隱藏文字 label 保留數字           |
| 初始 5 張手牌                               | MulliganScreen 手牌列                                                                      | 點選要重抽的卡                             | 選中 ring；完成後「等待對手」                                                                        | 橫向捲動，觸控目標 ≥44px                          |
| 引き直し / mulligan                         | MulliganScreen（浮層）                                                                     | 「重抽 N 張」/「保留手牌」雙按鈕           | 已確認顯示等待態                                                                                     | 手機全寬面板                                      |
| HP 100                                      | `PlayerStatus` 單軌血條（十格刻度）＋名稱右側加粗 HP 數字                                  | 唯讀                                       | 連續填充保留精確值；≤50 warning、≤25 danger 變色；戰鬥傷害時數字倒數、主條縮短並保留延遲紅色傷害殘影 | 所有斷點常駐可見                                  |
| HP 0 敗北                                   | GameOverScreen                                                                             | 結果頁主行動（再戰/回大廳）                | VICTORY/DEFEAT + 原因（HP 歸零）                                                                     | 全斷點                                            |
| Chronos 起始位置（真夜中）                  | `ChronosDial` 18 段分段環＋游標                                                            | 平時唯讀；指定位置效果時可直接點刻度       | 以游標與晝夜弧表示狀態，不顯示虛構的時刻或位置數字                                                   | 桌面大儀表→手機緊湊儀表，游標永遠可讀             |
| Chronos 夜/晝                               | 錶盤雙弧：夜=青 `--time-night`、晝=紅 `--time-day`（官方配色）                             | 唯讀                                       | 頂欄 🌙/☀️ + 全場晝夜色偏移（chrono-night/day）                                                      | 同上                                              |
| 卡牌時計値推進 Chronos                      | `ChronosResolutionLayer` 先同時顯示各卡時計值，再逐張飛向錶盤並讓徽章逐格推進              | 非阻塞、自動依序播放                       | 卡牌高亮、目前合計、最終推進格數                                                                     | 全斷點依卡牌與錶盤實際座標定位                    |
| 卡牌效果直接操作 Chronos                    | 來源卡高亮；推進／回溯依方向逐格移動徽章；指定位置先標記目標刻度再直接移動                 | 任意位置直接點錶盤刻度並確認；其餘自動播放 | 推進使用 accent、回溯使用 danger、指定位置使用 info；`±18` 仍完整繞行 18 格；不顯示具體時刻數字      | 全斷點依來源卡與目標刻度定位                      |
| Character NIGHT/DAY 攻擊力                  | 卡面詳情（CardDetail）雙値 + `BattleZone` 生效値                                           | hover / tap 開詳情                         | 生效側著色（夜青/晝紅）                                                                              | 詳情桌面側欄 / 觸控 bottom sheet                  |
| 戰鬥攻擊力比較與差值傷害                    | `BattleResolutionLayer` 依序顯示「基礎 ± 修正 → 實際」、雙方實際攻擊力減法、交鋒與 HP 變化 | 非阻塞；等待時計序列完成後自動播放         | 勝方綠、命中／傷害紅；減傷顯示「原始傷害 − 減免 = 最終傷害」；平手與全減免使用中性色                 | 依 BattleZone、Chronos、PlayerStatus 實際座標定位 |
| 特殊戰鬥結果                                | 平手顯示等式且不命中；全減傷改播護盾；雙零顯示「攻擊未成立」；負修正使用真正減號           | 非阻塞，自動選擇對應分支                   | 只有實際 HP 損失才使用紅色受傷與 HP 倒數                                                             | 同上                                              |
